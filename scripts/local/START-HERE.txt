Tocify Local

1. Extract the entire ZIP.
2. Double-click Start Tocify.command (macOS) or Start Tocify.cmd (Windows).
3. Tocify opens in your browser at http://127.0.0.1:3210.
4. Leave the launcher window open while you use Tocify. Close it to stop.

PDF editing and OCR run locally. OCR models and fonts download when needed.
Downloaded assets can be reused offline while they remain cached in your
browser. The help video streams online. AI recognition needs Internet access
and your own API key. For built-in providers the server on this computer sends
the key and selected content directly to the provider.

Tocify 本地版

1. 解压整个 ZIP。
2. macOS 双击 Start Tocify.command，Windows 双击 Start Tocify.cmd。
3. 浏览器会打开 http://127.0.0.1:3210。
4. 使用时保留启动窗口，关闭窗口即可停止服务。

PDF 编辑和 OCR 在本机运行。模型和字体用到时联网下载，
浏览器保留缓存时可以离线复用。帮助视频在线播放。
AI 识别需要联网和自备 API Key。选择内置供应商时，
本机服务会把 Key 和选定的内容直接发给供应商。
